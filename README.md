# Customer Segmentation Project

## Current Status

This project prepares transaction data for customer segmentation using text-based product descriptions.

### Completed

* Data loading and initial cleaning
* EDA on order-level dataset
* TF-IDF vectorization of product descriptions
* Combination of text features with numerical customer features
* Aggregation of transaction-level TF-IDF vectors to customer-level representations
* Initial handling of missing values

### Work in Progress

* Validation of customer-level feature matrix
* Integration of additional customer features
* Customer clustering and evaluation

### Technologies

* Python
* pandas
* NumPy
* scikit-learn
* SciPy

### Next Steps

1. Verify the customer feature matrix.
3. Apply clustering algorithms (e.g., K-Means).
4. Evaluate and interpret customer segments.
